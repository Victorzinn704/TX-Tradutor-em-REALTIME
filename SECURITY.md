# Politica de Seguranca

## Escopo

Este projeto captura e processa audio localmente. Relate vulnerabilidades ligadas a captura indevida, vazamento de audio/transcricoes, execucao de binarios nativos, logs, dependencias Python/Rust ou scripts de instalacao.

## Como reportar

Nao abra issue publica com audio privado, transcript sensivel, token, caminho local ou payload exploravel. Use um contato privado indicado no perfil do GitHub ou um aviso privado de seguranca quando o recurso estiver disponivel.

Inclua:

- sistema operacional e versao;
- modo de execucao usado;
- passos de reproducao;
- impacto esperado;
- evidencia redigida.

## Dados locais

Arquivos de audio, modelos baixados, logs de diagnostico e configuracoes pessoais devem ficar fora do versionamento. Exemplos publicos devem usar placeholders.
